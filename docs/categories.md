# 主分类映射说明

原 website 仓库 `archive/archive/<id>/**` 已按站点 `config.js TAG_CONFIG`
一级分类迁移至 `<分类>/<id>/**`（2026-08 二轮重排，此前一轮自创分类已废弃）。
id 与分类的对应关系以仓库根 `_meta/index-by-id.json`（构建产物）为最权威来源。

五个内容目录：非编码存储科技、潜影盒处理、编码存储科技、其他杂物、生产合成
（对应 config 键「生产/合成」，去斜杠存储）；版本标签不作目录维度。

归类算法与完整规则见根 README.md「主分类规则」；
当前「其他杂物」共 33 项，多为仅携带一级杂项标签或无显式二级标签的历史稿件，
符合 config.js 将其定义为兜底桶的设计。

后续新投稿的分类归档由维护者在合并投稿时决定目录位置；
`scripts/build.js` 只扫描非保留顶层目录，新增分类文件夹无需改代码。
